# InkPreview — Impeccable Design Context

## Design Context

### Users
People exploring a tattoo idea — GenZ-leaning consumers who want to *visualize a
design on their own body* before committing, often impulsively on a phone; plus
desktop users browsing and designing more deliberately. Studios (B2B) later. The
job-to-be-done: go from a vague idea to "I can see this on me, and I want it" in
under a minute, then hand a clean file to an artist.

### Brand Personality
Bold · magical · confident. Voice is hyped but tasteful, a little irreverent
(GenZ) — never corporate. The interface should evoke excitement, confidence, and
anticipation ("I can't wait to get this inked").

### Aesthetic Direction
**"Acid Ink."** Near-black studio canvas, acid-rave accents (acid-lime,
electric-cyan, hot-magenta) used as *spotlights*, not floods. Oversized kinetic
display type (Unbounded) + clean grotesk (Space Grotesk). Tattoo designs are
shown as **black-on-white flash cards** (the universal flash/stencil convention)
floating on the dark UI — the product IS the decoration.
- **References:** tattoo flash sheets, dark studio walls, club-flyer energy.
- **Desktop is editorial:** premium gallery restraint — generous whitespace,
  large refined type, a curated grid. Mobile is thumb-first and compact.
- **Anti-references:** corporate SaaS, cluttered/cringe-maximalist, and a
  mobile layout merely stretched onto desktop.

### Design Principles
1. **The tattoo is the hero.** Show real generated designs (flash), never abstract filler.
2. **Dark canvas, restrained accents.** Acid is a highlight; glow is intentional, never everywhere.
3. **Two real layouts.** Editorial desktop (top nav, big type, whitespace, curated gallery) vs thumb-first mobile (bottom nav, compact) — not one scaled to the other.
4. **Magic is felt, not stated.** Conjuring ritual, subtle motion, reveals — and always honor `prefers-reduced-motion`.
5. **Impeccable craft.** Deliberate type scale + vertical rhythm, aligned spacing, no orphaned elements; every screen feels intentional.
